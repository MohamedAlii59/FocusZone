COMMAND-BY-COMMAND BREAKDOWN
(For those who want step-by-step)

═══════════════════════════════════════════════════════════════════════════════

1️⃣  Open SQL Server Management Studio
    └─ Backup database (see Step 0 above)

2️⃣  Open PowerShell
    └─ Run: cd "E:\ITI Graduation Project\Claude Version\backend\Backend"
    └─ Run: Get-Location  (verify you're in right place)

3️⃣  Restore packages
    └─ Run: dotnet restore
    └─ Wait for: "Restored successfully"

4️⃣  Build solution
    └─ Run: dotnet build
    └─ Wait for: "Build succeeded"

5️⃣  Apply migration ⭐ THE MAIN ONE

6️⃣  Verify in SQL Server
    └─ Run SQL query (see Step 2 above)
    └─ Should return 10 new tables

7️⃣  Check Python
    └─ Run: cd "E:\ITI Graduation Project\Claude Version\backend"
    └─ Run: .\venv\Scripts\Activate.ps1
    └─ Run: python --version
    └─ Run: pip list | Select-String "pyodbc"

8️⃣  Test Python connection
    └─ Run: python -c "..." (see Step 4 above)
    └─ Should show ✅ Connection successful
